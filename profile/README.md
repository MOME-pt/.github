## MOME

Plataforma de desenvolvimento de projetos imobiliários residenciais, com sede no Porto. B Corp.

Desenvolvemos habitação em quatro linhas: construção para venda, cooperativas de habitação, arrendamento a custo e coliving. Tratamos a habitação como infraestrutura de longo prazo.

### Em destaque

**[Habitar Commons](https://github.com/MOME-pt/habitar-commons)**: classificação modular das formas de habitar, inspirada nos Creative Commons. 18 tipos de habitação, um manifesto legível por máquina e um validador aberto. Licença CC BY-SA 4.0.

**[Coeficientes de localização](https://github.com/MOME-pt/coeficientes-localizacao)**: mapas dos coeficientes de localização do IMI para habitação.
